# 🎓 Academic Context

## Project Classification

This is a **summer university project** with the following deliverables:

- Written report / dissertation
- Presentation / demo
- Development log / journal

**Timeline:** Full summer (~3 months)

---

## Core Academic Focus — AI-Assisted Development

The primary analysis lens for this project is the **evaluation of AI tooling in the software development process**. Rather than building an AI-powered application, the project evaluates how AI tools (e.g. GitHub Copilot, Claude, ChatGPT) influence:

- Code quality and speed of development
- Architectural decision-making
- Debugging and problem-solving
- Documentation generation
- Developer experience

This is a **meta-analysis of the development process itself**, using Kindling as the vehicle.

---

## Research Questions (Draft)

1. To what extent does AI-assisted development accelerate the delivery of a functional software tool?
2. How does AI tooling affect the quality of architectural decisions made by a developer?
3. What are the limitations of AI assistance in a novel, greenfield project?
4. How does AI-generated code compare to manually written code in terms of correctness, readability, and maintainability?

---

## Development Log

The development log should capture:

- Decisions made with AI assistance vs. independently
- Prompts used and quality of AI output
- Where AI suggestions were accepted, modified, or rejected
- Time saved (estimated) vs. time spent correcting AI output
- Qualitative observations about the development experience

> Consider keeping a separate `AI Log` note per development session, linked from here.

---

## Academic Framing

Kindling provides a concrete, measurable software project. The report can analyse:

- **Architecture decisions** — were they improved by AI consultation?
- **Code velocity** — did AI assistance speed up Phase 1 vs. Phase 2?
- **Error rates** — did AI-generated code introduce bugs?
- **Developer experience** — subjective assessment of AI as a pair programmer
